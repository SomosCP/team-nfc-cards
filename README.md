# team-nfc-cards
Sube index.html, styles.css, script.js, colaboradores.json y la carpeta imagenes a la raíz de GitHub Pages. 
Agrega las fotos reales. 
Abre ?id=andy o ?id=said. 
Duplica un registro JSON para cada integrante con una clave única. 
Teléfono: código de país y número (México: 52 y 10 dígitos). 
Habilidades: [{"titulo":"Cualidad","descripcion":"Descripción"}]. Los campos vacíos se ocultan. 
Confirma datos antes de publicar. 
El QR depende de una biblioteca externa CDN. 
El VCF se genera automáticamente. 
Para pruebas locales usa un servidor HTTP, no file://. 

No se han realizado pruebas en dispositivos físicos. 
Los perfiles son públicos; noindex no es una medida de privacidad.
